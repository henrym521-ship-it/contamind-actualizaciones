# contamind-actualizaciones

Repositorio **público** de ContaMind PRO. Aquí solo van:

- `contamind_config.txt`: configuración firmada (contacto, planes, versión nueva). La publica el Panel del Vendedor.
- `version_web.txt`: versión que se ofrece para descargar en hcsolucionesrd.com (si es más alta que la del config).
- **Releases**: el instalador más reciente. Lo publica solo el proceso «Publicar instalador en la web» (`.github/workflows/publicar-web.yml`).

Descarga directa: https://github.com/henrym521-ship-it/contamind-actualizaciones/releases/latest/download/ContaMind-Setup.exe

El código del programa NO está aquí.
